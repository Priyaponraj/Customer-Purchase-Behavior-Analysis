# Customer Shopping Behavior Analysis

## 📖 Project Overview

This project delivers an end-to-end data analysis of customer shopping behavior. It utilizes SQL for data extraction, transformation, and exploratory data analysis (EDA), and Power BI to visualize key metrics and trends. The goal is to uncover actionable insights regarding customer demographics, purchasing patterns, subscription impacts, and product performance.

## [🗂️ Dataset Schema](https://github.com/Priyaponraj/Customer-Purchase-Behavior-Analysis/blob/main/csba.csv)

The analysis is based on a single dataset (csba) containing the following columns:

* Customer Demographics: customer_id, age, gender, location, age_group

* Transaction Details: item_purchased, category, purchase_amount, size, color, season, review_rating, subscription_status, shipping_type, discount_applied, payment_method

* Behavioral Metrics: previous_purchases, frequency_of_purchases, purchase_frequency_days

## 🛠️ Tools Used

* Database: MySQL (for data storage and querying)

* Visualization: Power BI (for interactive dashboards)

## [🔍 SQL Analysis Breakdown](https://github.com/Priyaponraj/Customer-Purchase-Behavior-Analysis/blob/main/Customer_Shopping_Behavior_Analysis.sql)

Data Preparation: Creates the database csba, and performs initial sanity checks.

```
SELECT * FROM csba
limit 5;
```

Q1. Revenue by Gender: Calculates total revenue generated by male vs. female customers.

```select gender, 
       SUM(purchase_amount) as revenue
from csba
group by gender;
```

Q2. Discount Spenders: Identifies customers who used a discount but still spent more than the average purchase amount.

```
select customer_id,
	   purchase_amount 
from csba
where discount_applied = 'Yes' and purchase_amount > (select AVG(purchase_amount) from csba)
```

Q3. Top Rated Products: Ranks the top 5 products based on their average review rating.

```
select
    item_purchased,
    round(avg(CAST(review_rating as decimal(10,2))), 2) as `Average Product Rating`
from csba
group by item_purchased
order by avg(cast(review_rating as decimal(10,2))) desc
limit 5;

```

Q4. Shipping Preferences: Compares the average purchase amount between Standard and Express shipping types.

```
select shipping_type, 
	   ROUND(AVG(purchase_amount),2) as Avg_Standard_and_Express_Shipping
from csba
where shipping_type in ('Standard','Express')
group by shipping_type;

```

Q5. Subscription Impact: Compares average spend and total revenue between subscribed and non-subscribed customers.

```
select subscription_status,
       count(customer_id) as total_customers,
       ROUND(avg(purchase_amount),2) as avg_spend,
       ROUND(sum(purchase_amount),2) as total_revenue
from csba
group by subscription_status
order by total_revenue desc,avg_spend desc;
```

Q6. Discount-Heavy Products: Identifies the top 5 products with the highest percentage of purchases where a discount was applied.

```
select item_purchased,
       round(100.0 * sum(case when discount_applied = 'Yes' then 1 else 0 end)/COUNT(*),2) asdiscount_rate
from csba
group by item_purchased
order by discount_rate desc
limit 5;
```

Q7. Customer Segmentation: Segments customers into 'New', 'Returning', and 'Loyal' based on their previous_purchases count.

```
with customer_type as (
select customer_id, previous_purchases,
case 
    when previous_purchases <=1 then 'New'
    when previous_purchases between 2 and 10 then 'Returning'
    else 'Loyal'
    end as customer_segment
from csba)

select customer_segment,count(*) as "Number of Customers" 
from customer_type 
group by customer_segment;
```

Q8. Top Products per Category: Uses window functions (DENSE_RANK()) to find the top 3 most purchased products within each category.

```
with item_counts as (
    select category,
           item_purchased,
           count(customer_id) as total_orders,
           dense_rank() over(partition by category order by count(customer_id) desc) as item_rank
    from csba
    group by category, item_purchased
)
select item_rank,category, item_purchased, total_orders
from item_counts
where item_rank <=3;
```

Q9. Repeat Buyers & Subscriptions: Analyzes if customers with more than 5 previous purchases are likely to have an active subscription.

```
select 
      count(customer_id) as repeat_buyers
from csba
where previous_purchases > 5
group by subscription_status;
```

Q10. Age Group Revenue: Calculates the total revenue contribution of each age group.

```
select 
    age_group,
    sum(purchase_amount) as total_revenue
from csba
group by age_group
order by total_revenue desc;
```
